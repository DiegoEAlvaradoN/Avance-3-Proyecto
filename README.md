# Avance-3-Proyecto
Incorpora a tu proyecto libre uso de funciones

- Se desistió del uso de codigo mas avanzado
- Se amplio el inventario de 1 a 3 productos (computadora, telefono y raton) para mostrar el aprovechamiento del uso de la funcion
- Se implemento el uso de funciones con la función "comproducto()" para reutilizar el proceso de compra
- Se agrego un detalle a la experiencia mostrando el registro de unidades compradas, la cantidad restante y un resumen final de compras por producto
